# RD05 comparison package

This directory contains a separately versioned comparison of the independent
RD05 Reviewer A and Reviewer B reports supplied in the conversation.

- [`v1/`](v1/README.md) records the input reports, frozen reference snapshot,
  endpoint comparison, qualitative discrepancy register, and blank resolver
  worksheet.
- The reference snapshot is limited to permitted RD05 materials from commit
  `9af5992ecccc4d0c34f5a62f4767f9053254adf6`. No authored reference
  suggestions, custodian linkage, or answer key were consulted.

The comparison is not a completed resolution and does not establish
independent ground truth, human inter-reviewer reliability, or JEV
effectiveness.
